## overview

To authenticate API requests, you must include a secret key in the `Authorization` header of your requests. You can obtain the secret key from your [Dashboard](https://app.cepta.co/settings/api-credentials) once you’ve created your account and logged in.

Here’s an example of how to include the secret key in your API requests:

```bash
curl -X GET https://adapter.cepta.co/endpoint \
-H "Authorization: <SECRET_KEY>"
```

<Warning>
  **Always protect your secret keys**
  These keys grant access to your project and its associated resources, so they should never be shared or exposed in public repositories. Treat your keys as sensitive information to avoid unauthorized access to your account.
</Warning>
